Accessibility checks

What I tested before publishing.

  • Every text pair I measured passes WCAG 2.2 AA (4.5:1) in both themes.
  • Color never carries meaning alone. Problem, Decision, Evidence and Result use a shape and a word as well as a color.
  • The “Color vision check” button shows any page through protanopia, deuteranopia, tritanopia or achromatopsia.
  • A skip link and a visible focus ring support keyboard navigation.
  • Animations stop when the system asks for reduced motion.
  • The loading screen shows once per visit, leaves within 3.5 seconds, can be skipped with any key or click, and never flashes.
  • The theme control is a real switch: screen readers announce it as “Dark theme, on” or “off”.
